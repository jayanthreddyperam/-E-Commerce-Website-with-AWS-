# E-Commerce Website with AWS

## Features
- User Authentication (PHP & MySQL)
- Product Listings
- AWS S3 for Image Storage
- AWS RDS (MySQL) for transactional data
- Hosted on AWS EC2

## Setup Instructions
1. Clone the repository.
2. Set your AWS credentials in `/config/aws.php`.
3. Set DB credentials in `/config/db.php`.
4. Run `index.html` from a web server (e.g., Apache).
5. Add products via `product/add.php`.
6. View products on `index.html`.

## Technologies
- PHP, HTML, CSS, JS
- MySQL (AWS RDS)
- AWS S3 for media
